# Inkwell

Paint an eight-block song form. A live band follows the ink — piano, steel guitar, finger bass, trumpet, violin, and kit — so a four-bar loop becomes a finished arrangement.

Open the desk, seat the band, and play The Loop. Then paint block 1 Wash, block 4 Room, and block 7 Bare. The score climbs when neighbouring blocks stop wearing the same ink.

Not a mixer, not a vocal chain, not a four-bar return. The whole form.
